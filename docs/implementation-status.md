## 当前状态

项目以 Web 应用方式运行。5173 提供 Vite 页面，5192 提供本机 Pi Runtime API。模型供应商配置继续写入 Pi 的 `models.json` 和凭证存储。启动脚本为每次启动创建独立日志文件，避免旧 Node 进程仍持有固定日志文件时阻断重启。本轮还修复了状态脚本在 UTC+8 环境误解析 UTC 启动时间、把健康进程报成未运行的问题；重启后的状态识别和 Web/Runtime 健康检查已确认正常。

## 已接入

- 工作空间快照通过 `/api/workspace` 同步到本机运行时，并原子写入 `~/.pi/agent/ai-agent-team-workspace.json`。快照使用 `expectedRevision` 防止旧数据覆盖；关键业务转换走 `/api/workspace/command`，同样比较并递增版本。浏览器存储仍保存完整本地快照；页面启动时优先读取 Runtime。
- `/api/health` 用于运行状态页；模型目录、凭证和供应商配置由 Pi `ModelRuntime` 提供，目前目录包含 42 个供应商。
- 本机 Runtime API 使用随机短期浏览器会话令牌，并限制允许的 Host/Origin；页面通过同源代理申请令牌，令牌仅保存在当前页面内存中。
- 供应商配置页自动展示 Pi 注册的完整模型目录，支持新增、编辑、启用/停用模型；自定义模型写入 Pi `models.json`，启用状态保存在本机供应商设置文件。Runtime 启动时会幂等加入参考界面列出的 17 个 Z.AI Coding CN 模型。
- 用户提供的 OpenCode Go 凭证已通过 Pi API Key 登录流程保存在 Pi 本机凭证存储中。Runtime 开放 Pi 模型目录中的 OpenCode Go 模型，按各模型注册的 API 协议调用，并固定到官方服务地址；设置页可启停、编辑或新增模型。测试项目及工作空间默认模型仍为 `step-5-preview-free`。瞬时上游错误最多重试 5 次；上游端点可用性不由本机保证。
- 供应商目录和配置页使用各厂商官网域名的站点图标，图片加载失败时显示品牌缩写。
- 会议消息可调用选定的 Pi 模型；确认范围后的计划由模型按当前项目目标、小组和 Agent 生成。
- 任务运行会通过 Pi `createAgentSession` 启动受限 AgentSession。当前只注册项目文件列表/读取工具和 Run 输出写入工具；Agent 可读取授权项目目录中的文本，并在本次 Run 的分类目录中创建实际文件。Runtime 将输出文件落盘并提交待审核产物；无 Shell、命令执行、网页检索或客观测试工具。
- 每次任务执行的持久 Run 元数据和状态事件写入忽略目录 `.dev-runtime/task-runs.sqlite`；支持完成、失败、取消和启动时标记中断。运行取消会中止 Pi Session；重启后扫描安全文本输出，将部分产物以“参考”状态登记并保留原 Run 路径，Run 记录同步保存文件路径、字节数与 SHA-256。凭据路径、二进制、超限及不安全路径会跳过并提示检查；恢复可重复执行而不重复登记。业务工作空间仍使用 Pi Agent 目录下的 revision JSON；TaskRun SQLite 不代表工作空间整体已迁移到 SQLite。
- 出站操作先由 Runtime 校验项目、模型、操作类型及数据范围，并在内存暂存本次请求内容（最多 5 分钟）；浏览器按当前策略请求用户确认，Runtime 记录批准/拒绝后签发绑定会话、操作、供应商和模型的一次性授权。聊天、计划和任务接口只接受该授权，不再接受可直接触发模型调用的正文载荷。
- Pi `providerRequestGuard` 对每次最终供应商请求检查当前异步授权上下文、操作状态和供应商/模型匹配；无匹配批准上下文的请求会被拒绝。Runtime 将授权请求、决策、供应商请求放行、任务文件读取元数据、成功/失败/取消/过期/重启中断记录到 `.dev-runtime/task-runs.sqlite`；文件审计只保存相对路径、大小和 SHA-256，不保存文件正文或提示正文。
- “隐私与数据”设置页展示项目或工作空间级出站记录、事件和请求次数。任务运行先完成 Runtime 授权，再启动业务任务；启动失败会取消已批准但尚未使用的授权并记录未发送模型请求。
- 初次启动允许零个项目，并提示用户创建项目。创建项目使用居中对话框，调用本机系统文件夹选择器，按项目名创建专属文件夹并初始化 Git 仓库；工作台支持项目列表、归档/恢复和删除，删除项目时保留磁盘文件夹。
- 项目文件树默认没有文件和分类目录。计划批准时根据负责人建立需要的分类目录；Runtime 把任务模型文本、会议纪要和上传文本写入目录，并在 Artifact 上记录相对路径。上传大小上限为 1 MB。
- 发布交付版本前，Runtime 在 `05_最终交付` 写入清单，对项目文件执行 Git commit 并创建 `v0.x` 标签；界面显示标签和 commit 短哈希。Git 排除规则保护 `.env`、secret 和 credential 路径。
- 搜索、任务筛选、执行日志、运行状态、会议新建、角色菜单、项目菜单和文件操作均有实际行为。
- 新工作空间不再预填示例项目对话、任务、产物或活动。旧版浏览器数据会迁移并清理已知演示文案。
- 启动迁移识别旧“验收演示项目”记录：只有这类记录时迁移为空工作空间，与正式项目并存时只删除演示项目，保留其他工作空间数据。此前自动生成的空白“未命名项目”也会迁移为空工作空间。
- 会议回复、计划生成和任务运行均经 Runtime 出站授权；按“每次确认”设置请求用户确认，“项目范围内”使用项目预授权。会议回复移除了重复确认，计划请求新增发送前确认。

## 当前边界

- 受保护的业务状态由 Runtime 命令校验并持久化；普通资料编辑仍先由 Web Client 计算并提交完整 JSON 快照。版本号可检测跨标签冲突，但没有自动合并/恢复向导；JSON 写入没有 SQLite 事务。
- 浏览器 `localStorage` 目前保存完整工作空间快照，其中包含会议消息和产物正文；不能将其描述为“只缓存非敏感状态”。清理前需要设计旧缓存迁移，避免丢失离线数据。
- 任务执行仍绑定单次 HTTP 请求；SQLite 持久化 Run 记录并识别重启中断。已验证空 Run 与中途已写文件两种强制退出恢复；部分文件对账限于安全文本，且会跳过凭据路径、二进制和超限项。跨存储提交窗口、符号链接并发替换、队列、Lease 和断点续跑仍未实现。Agent 现可调用需逐条确认的本机命令工具；编译、Lint 和测试结果仍不会自动作为通过证据。
- Artifact 元数据和内容保存在本机工作空间 JSON 中，同时 Runtime 会把新增、编辑和上传的文本文件写入项目文件夹的分类目录；目前仅接受指定类型的文本文件，单文件上限 1 MB。外部直接修改/删除项目文件后的元数据同步、二进制与大文件仍未完成。
- 项目版本记录保存 Git 标签、commit 和交付文件数量。
- 尚未实现用户登录、远程协作、结构化测试工具、供应商模型的真实联网验收和 Run 断点恢复。Agent 可申请逐项确认后运行本机命令，但没有独立的测试报告采集工具。假 Provider 已覆盖主要 HTTP 授权/生命周期场景、AgentSession 文件读取审计、静态目录安全矩阵和部分产物中断恢复；符号链接竞争条件、跨存储提交窗口故障注入和 UI 审计呈现仍未验收。Pi 请求失败会显示错误并更新持久 Run 状态。
