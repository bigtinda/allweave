# 全系统交互逻辑审计

审计日期：2026-10-11  
范围：`apps/web-prototype`、`apps/local-runtime/src/model-provider-server.mjs` 与 Pi SDK 调用边界。此次按页面检查导航、表单、菜单、弹窗、筛选、拖拽、审批、异步反馈和持久化调用；未连接真实供应商。代码路径已具备受限项目文件读取/写入，但未进行真实任务文件操作与完整端到端验收。

## 当前数据与调用链

```text
React 页面
  → ProductClient（本地内存状态 + localStorage 缓存）
  → 普通编辑：PUT /api/workspace（expectedRevision + 工作空间快照）
  → 受保护状态：POST /api/workspace/command（expectedRevision + 项目命令）
  → 本机 Runtime 校验 revision/状态转换并原子写入 JSON 文件

会议和计划文本生成
	→ Runtime 出站预授权 → 用户决定 → 一次性授权令牌
	→ /api/model-runtime/chat|plan
  → Pi ModelRuntime.completeSimple

任务文件执行
	→ Runtime 出站预授权 → 用户决定 → 一次性授权令牌
	→ /api/model-runtime/execute
  → Pi AgentSession + 受限项目文件工具

最终供应商请求
	→ Pi providerRequestGuard 校验当前授权上下文
	→ SQLite 记录供应商请求和已读取文件元数据
```

Pi 供应商目录、模型配置和认证流程确实接入 Runtime。关键审批、任务和交付状态现由版本化业务命令校验；团队配置、会议消息等普通资料仍由前端编辑后提交整份快照。工作空间 JSON 有 revision 和串行原子写入；独立 SQLite 用于持久 TaskRun 元数据、状态事件和模型出站授权审计，工作空间事务、多窗口自动冲突恢复仍未实现。任务端点创建 Pi AgentSession，允许列出/读取项目文本并向受限 Run 输出目录写文件；没有命令执行、自动测试或客观检查。

## 页面入口核对

- **项目工作台**：创建项目、项目切换、打开、归档/恢复、删除、进入团队/会议、活动和进度；项目计数及进度由当前客户端快照计算。
- **组织架构设计**：角色搜索/分类/拖拽、跨组移动、小组增删、缩放/专注视图、Agent 选择、配置标签、保存/进入会议。画布拖拽只调整小组归属，没有位置持久化；配置能力有缺项，见 P1-3、P1-4。
- **会议室**：新建会议、消息发送、需求确认、计划生成、计划审批、相关任务跳转、会议纪要。聊天/计划会调用 Pi 模型，历史、流式和持久审批不完整，见 P0-1、P1-5、P1-6。
- **任务中心**：执行下一项、看板筛选、任务详情、日志/产物、持久运行记录、取消和审核/返工。Pi AgentSession 可读取受限项目文本并写入 Run 产物；没有命令/测试工具、队列或断点续跑，见 P0-2、P0-5、P1-7、P1-8。
- **角色市场**：搜索/分类、详情菜单、自定义角色、加入/配置。模板为前端常量，无法重复安装同模板实例，见 P1-3。
- **交付中心**：文件树折叠/筛选、搜索、上传、预览、下载、新页打开、发布版本和验收。项目文件树随实际生成目录变化；Artifact 正文同时保存于 Runtime 状态和项目文件。Git tag 标记每次发布，历史文件差异和预览仍见 P1-9。预览区已改为填充可用高度。
- **设置**：项目信息保存、供应商与模型目录/认证/增删改启停、默认模型、隐私偏好、Runtime 状态和重置。模型目录与认证接 Pi Runtime；隐私排除路径和多数业务设置仍是快照字段，见 P1-10、P1-12。

本次静态核对覆盖上述页面可见的导航、表单、按钮、开关、菜单、搜索/筛选、拖拽、弹窗、状态反馈和 API 调用入口；P2 中的键盘、读屏、多窗口尺寸项还需浏览器人工走查，不能仅凭静态代码检查标为验收通过。

## 本批状态流修复

- Runtime 为会议回复、计划生成和任务运行签发绑定会话、操作、供应商及模型的一次性出站授权；Pi 最终请求 Guard 拒绝没有匹配授权上下文的请求。请求正文在 Runtime 内存暂存最多 5 分钟，审计只保留范围、哈希、大小、供应商请求和文件读取元数据。
- Runtime SQLite 审计记录批准、拒绝、取消、失败、过期、重启中断及最终供应商请求放行；设置页可按项目或整个工作空间查看。任务须先获得授权再切换到执行状态；启动失败时取消未使用授权。
- 工作空间 PUT 和命令现在都需要 `expectedRevision`；Runtime 在串行队列中比较版本，成功写入后递增 revision，过期请求返回 409 和服务端版本。
- 计划批准、需求确认、任务开始/完成/失败/审核、交付物提交、版本发布/验收、项目归档/删除和重置走 Runtime 命令；普通快照不能直接更改受保护状态。命令的审核拒绝条件、任务状态与项目规则由服务端校验。
- ProductClient 等待关键命令结果后再更新视图；普通快照写入维持异步，并在侧栏显示保存中、版本冲突或失败。冲突会阻止旧 revision 的后续写入，恢复向导仍待做。
- Runtime 使用随机短期会话令牌保护同源 API；Pi 最终请求 Guard 要求 OpenCode Go 模型与本次授权匹配，并将请求固定到官方服务 URL。供应商凭证经 Pi API Key 登录流程保存，当前服务确认已授权；本轮未发起推理请求。
- 任务 Run 现在使用 SQLite 记录模型、Agent、计划版本、输入摘要、状态事件和写入产物清单；支持用户取消和启动时识别未结束的 Run。该数据库保存在被 Git 忽略的 Web `.dev-runtime` 目录；主工作空间仍使用 JSON。
- 启动脚本改用每次启动的独立日志文件，避免上一次 Node 进程占用固定日志而阻断启动；本轮在 5173/5192 成功重启并经同源 API 健康检查。
