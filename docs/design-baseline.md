# W0 设计基线与 W1 原型交互

## 视觉基线

以 `../../ui设计示意图/总览.jpg` 为六页统一视觉参考，`../../ui设计示意图/团队设计.jpg` 补充组织画布，会议室、任务中心和交付中心独立图补充细节。实现采用浅灰工作区、白色内容卡片、深色正文、蓝色主操作、低饱和状态色和紧凑信息密度。

共享 AppShell：固定全局导航、项目上下文栏、页面主体、通知/用户入口、设置抽屉。组织架构设计采用“角色组件库 + 组织画布 + Agent 配置面板”；会议室采用“会议列表 + 对话 + 决策栏”；任务中心采用状态看板和任务详情；交付中心采用文件目录、列表/预览和版本详情。

设计 Token 位于 `src/styles.css` 的 `:root`。布局先适配 1440×900，再适配 1280×800；窄窗口时收起侧栏和详情栏，不压缩正文到不可读。

## 页面与操作

| 页面 | 核心操作 | 保护条件 / 提示 |
|---|---|---|
| 工作台 | 创建项目、打开最近会议/任务/交付 | 新项目只初始化浏览器演示状态。 |
| 组织架构设计 | 搜索角色、拖放/添加成员、建组、选择模板、编辑 Agent、保存 | “启动团队”只进入需求会议，不等于执行授权。 |
| 需求会议 | 发消息、确认需求、生成计划、查看任务拆分、批准计划 | 需求未确认禁用计划生成；草案未批准不创建任务。 |
| 任务执行中心 | 查看分栏、打开详情、模拟推进、审核通过/驳回返工 | 顶部与详情明确标出“模拟执行”，没有真实命令或文件运行。 |
| 角色市场 | 搜索/分类、安装官方模板 | 安装只添加演示角色实例，不启用权限或联网。 |
| 项目交付中心 | 浏览文件预览、发布版本、提交验收 | 发布表示本地演示归档，不代表远程部署。 |
| 设置抽屉 | 模型、隐私/外发范围、运行环境模拟 | 不显示密钥输入框；所有字段注明演示配置。 |

## 状态提示

空态、待审批、运行中、待审核、返工中、已完成、待验收、已验收均使用明确文字和状态徽标。任何页面不把模型输出当成正式批准，也不把未执行检查显示为通过。
